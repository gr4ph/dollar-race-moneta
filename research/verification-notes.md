# Verification notes (Researcher) - checked 2026-10-27

Legend: CONFIRMED = read on an official Etsy page (help.etsy.com / developers.etsy.com) via fetch. UNVERIFIED = only from search snippets, third-party sites, or an official page I could not open (etsy.com/legal/* returns 403).

## a) IVA/VAT on Etsy seller fees for Mexico-based sellers
- CONFIRMED (partially): Etsy's "How VAT Is Collected on Seller Fees" lists Mexico under "VAT for shops based in Indonesia, Ireland, Mexico, Japan, Serbia, South Africa, Switzerland, and Vietnam", stating Etsy is required to charge VAT on applicable fees whether or not you submit a VAT ID. Charges show up monthly in the Payment account balance. The article says "applicable / VAT-eligible seller fees" without listing listing/transaction/processing separately, and says VAT on Etsy Payments processing fees applies only "where required" (Mexico not clearly stated for that).
- RATE: the article states no rate. UNVERIFIED. Mexico's general IVA rate is 16% (standard rate per secondary guides, e.g. KPMG 2016 guide), so expect about 16% on the fee amounts, but check the first monthly statement.
- Separate item, CONFIRMED: Etsy also WITHHOLDS from Mexican sellers' sales (not a fee VAT): ISR 2.5% on all sales with a valid RFC (individual rate rose from 1% to 2.5% on 2026-01-01); IVA 8% withheld only on orders to Mexican buyers; with NO valid RFC it is 20% ISR + 16% IVA (up to 36%). So for a US buyer with a valid RFC: 2.5% withheld; without RFC: 20%. Shaky should provide a valid RFC in Etsy.
- Sources: https://help.etsy.com/hc/en-us/articles/360040584433-How-VAT-Is-Collected-on-Seller-Fees ; https://help.etsy.com/hc/articles/8709142835223 ; https://assets.kpmg.com/content/dam/kpmg/es/pdf/2016/11/indirect-tax-guide-mexico-2016.pdf

## b) Offsite Ads
- CONFIRMED: 15% fee on orders attributed to an Offsite Ad for shops under the threshold; 12% for shops that made $10,000 USD or more in any consecutive 365-day period (then required to participate for the lifetime of the shop). Fee per order is capped at $100.
- CONFIRMED: shops that have never made $10,000+ in any consecutive 365 days CAN opt out (Shop Manager > Settings > Offsite Ads > Opt out).
- Source: https://help.etsy.com/hc/articles/360000338367

## c) Digital download limits and returns
- CONFIRMED: up to 5 digital files per listing, max 20MB each. Allowed types: .bmp .doc .gif .jpeg .jpg .mobi .mov .mp3 .mpeg .pdf .png .psp .rtf .stl .txt .zip .ePUB .iBook. (Canva template delivery = a PDF/TXT containing the template link, which fits.)
- CONFIRMED: Etsy says "It's not possible to set return or exchange policies on your digital listings"; if a buyer has a problem the seller can "resolve the issue as you see fit". So there is no "returns accepted" option to turn off. Etsy's Purchase Protection may still cover a digital order that is not as described or never delivered (secondary summary of help pages, UNVERIFIED wording). Cancelling an order is the only way to revoke file access.
- Sources: https://help.etsy.com/hc/en-us/articles/115015628347-How-to-Add-Files-to-a-Digital-Listing ; https://help.etsy.com/hc/en-us/articles/7869401615255-How-do-I-Set-Return-Policies-on-My-Listings

## d) Etsy Open API v3
- Registering: CONFIRMED. Developer Portal (https://www.etsy.com/developers) > "Create a seller app" (own shop only) or "Create a personal app"; you get an API keystring + shared secret. Seller app requires an active shop in good standing and no existing registered app; steps: sign in, name app, explain why, accept terms. Help article: "usually approved within a few minutes".
- Approval time: Seller app = minutes (CONFIRMED). Personal app = "deeper review", no official timeframe (CONFIRMED that none is stated); third parties report 20-30+ days (UNVERIFIED). Commercial access = manual review, not needed for us. Seller app cannot access other sellers' data and cannot build a platform for other sellers.
- Read-only public endpoints with just the key: official Authentication page says the API key (x-api-key header) is required on every request and OAuth is additionally required only for private user data or writes. But whether findAllListingsActive (GET /v3/application/listings/active, `keywords` param) works with the key alone, and whether a SELLER app (scoped to your own shop) is allowed to call it, is UNVERIFIED: third-party connectors show key-only calls; an Apify note reports a 403 for unauthenticated calls. Test it with the real key once an app exists. Fallback for keyword research: manual Etsy search by Shaky.
- Draft listing + file + images: CONFIRMED in the official Listings tutorial. createDraftListing needs quantity, title, description, price, who_made, when_made, taxonomy_id. A digital file CANNOT be attached in createDraftListing: set the listing `type` to "download" with updateListing (PATCH), then uploadListingFile (binary `file` or existing `file_id`), uploadListingImage (binary `image`), then updateListing state="active". OAuth scopes listings_r + listings_w (listings_d to delete). OAuth 2.0 with PKCE is needed; there is no sandbox (third-party report, UNVERIFIED).
- API Terms clauses on AI / automated listing creation: UNVERIFIED. etsy.com/legal/api returns 403 to fetch. Etsy's help article on seller apps lists "Generating draft listings in bulk" as a sample use of the API and has no AI-specific terms. A search snippet of an ARCHIVED version of the API terms says developers may not use the API to collect Etsy content for "analytics, machine learning, licensing, or content removal unless expressly authorized" (relates to reading Etsy data for ML, not to creating listings; may be outdated). Shaky should read https://www.etsy.com/legal/api in a browser before accepting the terms.
- Related, CONFIRMED on help.etsy.com: "Bot-generated content" is not allowed on Etsy (see e). Safest design: scripts create DRAFTS, a human (Shaky) reviews and publishes each one.
- Sources: https://help.etsy.com/hc/en-us/articles/41918478450967-How-to-Register-a-Seller-App-with-Etsy-s-API ; https://help.etsy.com/hc/en-us/articles/360025870013-How-to-Use-Etsy-s-API ; https://developers.etsy.com/documentation ; https://developers.etsy.com/documentation/essentials/authentication ; https://developers.etsy.com/documentation/tutorials/listings

## e) AI disclosure and related rules for digital items
- CONFIRMED (help.etsy.com "What Can I Sell on Etsy?"): "Sellers must disclose within their listing description if an item is created with the use of AI." "Seller-prompted AI creations must disclose the use of AI." Not allowed: "Bot-generated content", "AI-generated functional instructions, such as craft patterns, recipes, and instructions", "AI prompt bundles". "Digital items listed in your store must be made and/or designed by you, the seller." Digital items may be premade files or custom files.
- Newer, reported by third parties only (UNVERIFIED against Etsy's own announcement, which I could not open): Etsy announced AI-policy updates on 2026-10-22 ("Important updates to AI use on Etsy" in the Seller Handbook): fully bot-generated listings with no human involvement are removed; AI art still allowed with disclosure and a real creative role; most digital downloads should show a visual preview or excerpt of what buyers receive; AI-generated functional instructions are banned. One site says the listing form has a "With an AI generator" option under "How it's made" (UNVERIFIED). Items are labelled via the Creativity Standards ("Designed by" etc.).
- Practical for us: do not sell AI-written recipes/patterns/guides; include real previews of the actual file; add an honest disclosure line (e.g., "Designed by the shop with the help of AI tools") if AI tools were used; a person must review each listing before it is published.
- Sources: https://help.etsy.com/hc/en-us/articles/360024112614-What-Can-I-Sell-on-Etsy ; https://help.etsy.com/hc/en-us/articles/34707360607511-Reasons-a-Listing-May-Be-Removed-Under-Etsy-s-Creativity-Standards (page returned 404 to me on the short link, listed in search) ; https://www.valueaddedresource.net/etsy-bans-ai-patterns/ (third party) ; https://www.inkfluenceai.com/blog/etsy-ai-rules-update-october-2026 (third party)
